## adding new routes using router-link
1. router-link is a vue navigation component and it helps preventing the page from reloading. it is used to inject component rather than reloading the whole page.

2. we can do it by using two techniques using path and name inside router-link tag. __check welcome page nav element__

3. __active-class__ can be used to allow links to be active. it add a css to make a link active. <br>
`<router-link to="/admin/dashboard" active-class="active"> Dashboard </router-link>`
